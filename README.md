> [!IMPORTANT]
> # Build & Use
> First clone correct repository:
> ```sh
> git clone https://github.com/Szmelc-INC/Eternal-Acid-Tracker
> cd Eternal-Acid-Tracker
> ```
> Install deps [nodejs + npm] (parcel for typescript)
> ```sh
> sudo npm install -g parcel
> ```
> Then build Typescript with
> ```sh
> bash build.sh
> ```
> Then start it with 
> ```sh
> php -S localhost:<port>
> ```
> Or do it all in one go by:
> ```sh
> bash start.sh
> ```
> Then access it on `http://localhost:2137` in browser
